Kya nahi chalta

2048-bit random RSA — factoring infeasible. Koi tool nahi tod sakta. Agar n me koi weakness nahi (inferius style balanced 100-bit primes), to honest answer: key missing.

PEM/SSH: public key paste karo → n, e nikal ke attacks try karo.

AES / DH / BIP39

  • AES-CBC/CTR/ECB: key + IV chahiye (hex). Key ke bina possible nahi.
  • AES-ECB detect: duplicate blocks scan — bina key pata chal jata hai mode.
  • DH: chhote p pe discrete log. p > 2^40 practically infeasible.
  • BIP39: mnemonic → seed (PBKDF2).
  • Password strength: entropy bits + crack-time estimate.

Hashes

MD5 · SHA-1 · SHA-256 · SHA-384 · SHA-512 · HMAC. Identifier length se algorithm batata hai. Crack: built-in wordlist + 0–99,999 numeric. bcrypt/Argon2 design se slow — brute impossible.

Text stego (tool me hai)

  • Zero-width: U+200B/200C/200D/FEFF ko bits me convert → text.
  • MSB/LSB: bit string → text (8-bit groups).
  • Bit-flip stego: text ke andar chhupi bits.

Image / audio stego (tool me NAHI)

Iske liye alag tools: zsteg, steghide, binwalk, aperisolve, exiftool. Tool sirf offline crypto kar sakta hai — image pixels me nahi jaata.
